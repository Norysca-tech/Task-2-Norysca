## Project 2: Exploratory Data Analysis (EDA)

**Tool used:** Python (Pandas, Matplotlib) via Google Colab

### Key Findings
- Only 19.25% of orders successfully delivered — 41.4% cancelled/returned
- Instagram is top revenue channel (€275,285)
- 8 high-value outlier orders detected (€3,334–€3,456) — likely VIP buyers
- TotalPrice is right-skewed — most customers spend under €1,000
